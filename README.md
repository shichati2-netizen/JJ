# כלי Anti-Executable — פרויקט JJ

הפרויקט מרכז את הקבצים מה-ZIP ואת שני הקבצים שהועלו בנפרד, ומכין כלים native ל-Windows.

## מה זוהה בקבצים המקוריים

| שם שהתקבל | מה הוא בפועל |
|---|---|
| AE_OpenClose.bat | קובץ Batch שמפעיל AE_OpenClose.ps1, אך קובץ ה-PS1 עצמו לא סופק |
| AE_Tools.PS1.TXT | למרות הסיומת, התוכן הוא Batch wrapper שמפעיל AE_Tools.ps1; מנוע ה-PS1 חסר |
| AE_Items_ToAdd.BAT וגם AE_Items_ToAdd (1).BAT | שני עותקים של קובץ טקסט עם מקטעי WHITELIST/BLACKLIST, לא קובצי Batch |
| AE_AddItems.bat, AE_AllInOne.bat, AE_RemovePassword.bat | עטיפות Batch שמסתמכות על AE_Tools.ps1, שאינו בארכיון |
| AEConfig.xml | הקובץ שסופק הוא בינארי/מוצפן: אחרי BOM של UTF-16LE מופיעים בתים שאינם XML קריא |
| README.TXT | מסביר שימוש במנוע AE_Tools.ps1 ובקובץ מוצפן מוכן, אך שני הקבצים האלה אינם קיימים ב-ZIP |

הקבצים בעלי הסיומות השונות אינם בהכרח קבצים שונים. השמות והסיומות לא תאמו לתוכן בפועל.

## הכלים שנבנים בפרויקט

### 1. AE_Otzaria_Auto.exe
- בודק את הקובץ E:\OTZARIA\OTZARIA.EXE.
- דורש גודל מדויק של 4,783,616 בתים.
- בודק את גרסת הקובץ 0.9.98.32466 מתוך משאב הגרסה של Windows.
- מחשב SHA-1 ומייצר AE_Otzaria_ITEM.xml ליד קובץ ה-EXE.
- כותב הצלחה/כישלון לקונסול בלבד.

### 2. AE_Manual_Entry.exe
- מציג חלון בחירת קובץ.
- מאפשר לבחור WHITELIST או BLACKLIST.
- קורא את גרסת הקובץ ומחשב SHA-1.
- יוצר קובץ טקסט עם מקטע והרשומה בפורמט ITEM, ליד קובץ ה-EXE.

**חשוב:** לפי תבנית ה-XML שסופקה, השדה SIGNATURE מכיל 40 תווי hexadecimal, ולכן הכלים מחשבים SHA-1. זהו אומדן שנגזר מהדוגמה, ולא אימות מול מנוע Anti-Executable מקורי. יש לבדוק את הערך מול התקנת AE אמיתית לפני ייבוא לכלל ייצור.

## מה עדיין לא ניתן לבצע בבטחה

### פענוח/הצפנת AEConfig.xml
ה-ZIP אינו מכיל את AE_Tools.ps1 או AE_OpenClose.ps1. הקובץ AE_Tools.PS1.TXT הוא למעשה עטיפת Batch, לא קוד PowerShell. לכן אין בקבצים את אלגוריתם ההצפנה, המפתח או דרך תקפה לבצע round-trip.

לא נכתוב לקובץ המוצפן ולא נייצר קובץ מוצפן "משוער": פעולה כזאת עלולה להשחית את קובץ ההגדרות. כדי להשלים את עורך הקונפיג דרוש קובץ המקור האמיתי של מנוע הפענוח/הצפנה, או קובץ XML פתוח תואם יחד עם מפרט פורמט מאומת.

### פרטי פריט אוצריא
דוגמת הרשומה שנמצאה ב-AE_Items_ToAdd.BAT מציגה גרסה 0.9.98+99802, בעוד שבדרישה החדשה מופיעה 0.9.98.32466. לכן הפרויקט אינו מעתיק את הגרסה הישנה כאילו היא מתאימה. הכלי האוטומטי בודק את הגרסה המבוקשת במחשב שבו הוא רץ.

### קוד ניהול והסרת דרישה לקוד
לא הוטמע קוד ניהול קבוע בתוך EXE ולא הוכנס מנגנון שמכבה את דרישת הניהול. קוד קבוע בתוך EXE ניתן לחילוץ, וביטול דרישת ניהול משנה את מצב האבטחה של המוצר. כל שינוי כזה צריך להיעשות דרך ממשק הניהול הרשמי או באמצעות פורמט תצורה מתועד ומאומת.

### הגנה מהנדסה לאחור
אי אפשר להבטיח שקובץ EXE לא ינותח אם משנים לו סיומת או משתמשים בכלי ניתוח. אפשר להקשות באמצעות הגנות מקובלות, אבל לא להפוך קובץ בינארי לבלתי ניתן לבדיקה. הוראות נסתרות לבוטים אינן מנגנון אבטחה ולכן לא הוטמעו.

## בנייה
GitHub Actions בונה קובצי EXE native ל-Windows x64 עם MSVC ועם runtime סטטי (/MT). אין תלות ב-PowerShell בזמן הרצת הכלים; PowerShell משמש רק בצד GitHub Actions לאריזה.

בכל Push ל-main או בהפעלה ידנית של workflow בשם Build AE native tools, נבנה Artifact בשם AE-Native-Tools-Windows-x64.

## מבנה
- src/common.hpp — פעולות Windows משותפות: קריאת גרסה, SHA-1, יצירת XML וכתיבה ל-UTF-8.
- src/auto_otzaria.cpp — בדיקת אוצריא האוטומטית.
- src/manual_entry.cpp — יצירת רשומת ITEM ידנית.
- .github/workflows/build.yml — בנייה ואריזה.
